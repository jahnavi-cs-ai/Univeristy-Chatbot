# 🎓 Chaitanya University Chatbot

An AI-powered university assistant chatbot developed to help students, faculty, and visitors quickly access information related to admissions, courses, departments, fees, facilities, examinations, and other university services.

The chatbot uses Natural Language Processing (NLP) techniques to understand user queries and provide accurate responses based on a predefined intents dataset.
## 🚀 Features

- 💬 Natural language conversation
- 🎯 Intent-based query classification
- 📚 University-specific information retrieval
- 🏫 Admission and course guidance
- ❓ Frequently Asked Questions support
- ⚡ Fast response generation
- 🔄 Easy to update training data
- 🖥️ User-friendly interface


## 🛠️ Technologies Used

- Python
- Natural Language Processing (NLP)
- TensorFlow / Keras
- NLTK
- NumPy
- JSON

## 🧠 How It Works

1. User enters a query.
2. Text preprocessing is performed using NLP techniques.
3. The trained model predicts the user's intent.
4. The chatbot selects the most appropriate response.
5. The response is displayed to the user.

---

## 📊 Dataset

The chatbot is trained using a custom `intents.json` dataset containing:

- Greetings
- Admissions
- Courses
- Departments
- Placements
- Fees
- Scholarships
- Hostel Facilities
- Examination Details
- Contact Information
- General University Queries

## Example Conversation

**User:** What courses are offered?

**Bot:** Chaitanya University offers Undergraduate, Postgraduate, and Professional programs across multiple disciplines.

**User:** How can I apply for admission?

**Bot:** You can apply through the university admission portal or contact the admissions office for assistance.
